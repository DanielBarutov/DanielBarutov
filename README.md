## ☀️ Немного обо мне

- 🛠️ В разработке с 2019 года, около четырёх лет в продуктовых командах.
- 🐍 Основной стек — Python, FastAPI, Django и PostgreSQL.
- 📨 Работаю с асинхронностью, очередями, Kafka и фоновыми задачами.
- 🔍 Люблю разбираться в медленных SQL-запросах и делать системы наблюдаемыми.
- 🧩 Использую Clean Architecture, CQRS и явные границы модулей там, где они помогают задаче.
- 🌱 Развиваю [HubShell](https://github.com/DanielBarutov/HubShell) — систему управления компьютерным клубом. Проект в разработке.
- 🤝 Открыт к предложениям по Python backend: удалённо или в Москве.
